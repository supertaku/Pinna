# Pinna logo

The primary mark combines a capital **P** with the silhouette of the pinna, the visible outer ear.

- Primary teal: `#0F766E`
- Warm cream: `#F4F7F2`
- Monochrome ink: `#0B1F1D`
- Keep clear space around the mark equal to the width of its vertical P stem.
- Use the app-icon artwork for launcher icons and the transparent primary mark for light surfaces.
